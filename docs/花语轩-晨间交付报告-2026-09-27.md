## 2. 本轮做了什么

### 2.1 业务功能增量
- **B8 优惠券/满减活动**（本轮主交付）：`Coupon`/`UserCoupon` 双表 + `CouponPolicy` 服务端裁决；
  现金券/折扣券（带封顶）、全场或分类专享、领取窗口与有效期、发行量与每人限领；
  扣库存与核销均用**条件 UPDATE**，并发下不会超发；订单取消按单回滚为 `unused`。
  金额链路固定为 `商品总价 → VIP 95% → 优惠券 → 积分（≤折后 20%）→ 应付（下限 ¥0.01）`。
  接口：`/api/coupons/receivable`、`/claim`、`/mine`、`/quote` + 后台 `/api/admin/coupons/**`。
- **首页与详情页营销位联动**：`huBindCouponPromo()` 拉取可领券渲染推广条，详情页按商品分类过滤专享券，
  一键领取后按钮转「已领取」；无可领券时整条隐藏，不留空壳。
- **B14 搜索增强**：`SearchTokenizer` 纯 JDK 分词（拉丁整词 + 中文相邻二元组）+ Specification 组合谓词，
  AND 无结果自动 OR 兜底；联想下拉 + 历史词（`search_keyword` 表、`V6` 的 pg_trgm GIN 索引）。
- **后台增强（D 类收尾）**：操作审计日志（`admin_audit_log`，`V5`，写操作全量留痕、敏感字段脱敏、可按模块/关键词检索）、
  商品批量上下架与批量删除、库存直改、订单发货与 CSV 导出、用户重置密码与启停、看板 ECharts 趋势图。

### 2.2 前台界面现代化（你上一条明确诉求）
- 设计令牌由「米白/雅绿/衬线」复古编辑风 → **冷白 + 墨黑 + 翡翠绿 + Inter** 商务精致风，全站统一圆角/描边/阴影/缓动。

  商品卡重排徽标、划线价、评分、收藏态。
- 个人中心族（资料/订单/收藏/地址/设置）改为「账户侧栏 + 会员·积分·状态三卡 + 表单分区」。
- 购物车 / 结算 / 订单详情三页重写为组件化布局：七列购物车网格（含不可购灰态）、粘性金额卡、
  地址与支付方式单选卡、五节点订单进度条。
- 「记住我的登录状态」已生效（HMAC 签名 Cookie + `RememberMeFilter`），并修掉登录重定向 URL 带 `;FLOWERSESSIONID` 的问题。

### 2.3 关键缺陷修复
| 现象 | 根因 | 处理 |
|---|---|---|
| 后台轮播图/公告表格恒「数据为空」 | 两页未接 `admin-common.js`，Layui 按 `code:0` 判成功而后端返回 `code:200` | 接入公共脚本对齐响应约定 |
| 上述两页「添加」按钮无反应 | `layer` 只在 `layui.use` 闭包内可见 | 弹窗与提交逻辑收进 `layui.use(['table','layer','form'])` |
| 编辑弹窗把库里的值裸拼进 HTML | 模板字符串直插 | 统一 `huAdmin.esc()`，图片走 `safeUrl()` |
| 一次提交重复 POST 多次 | 每次开弹窗重复注册 `form.on('submit')` | 改为按 id 取值 + 按钮一次性 click 绑定 |
| 勾 2 件结算却清空整车 | 旧实现传 `clearCart:true` | 传 `false` + 仅对勾选项逐条删除，未勾选商品保留 |
| 结算页 `bank` 支付方式被服务端拒绝 | 前端选项与 `OrderDtos.payMethod` 不一致 | 前端只保留 wechat/alipay/balance/offline |
| 未匹配的 `/api/**` 返回带堆栈的原始 JSON | 该路径不经过 `@RestControllerAdvice` | 新增 `ErrorPageController`：API→`{code:404}`，页面→品牌 4xx 视图 |
| 后台右固定「操作」列按钮被截成省略号 | layui 默认 15px 单元格内边距挤压 | `admin-theme.css` 全局收紧固定列内边距 + 逐表校正列宽 |

## 6. 操作备忘（本机）

```bash
# 只编译，不重启进程：devtools 监听 target/classes 变化自动热重启
./mvnw -o -q compile
# 热重启有延迟，探测前先等就绪
for i in $(seq 1 25); do curl -s -o /dev/null http://localhost:8080/ && break; sleep 3; done
```

- 模板（`src/main/resources/templates/**`）与静态资源（`static/**`）改动**必须** `./mvnw -o compile` 才生效——运行时读的是 `target/classes`。
- 每次编译都会触发 devtools 热重启，**内存会话随之失效**，脚本化验证前需重新登录。
- 新增 Maven 依赖需要整进程重启（热重启复用启动 jar 列表），本轮已刻意避开。
